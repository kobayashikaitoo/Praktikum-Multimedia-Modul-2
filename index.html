2. HTML5 Audio

Tag <audio> dengan atribut controls menampilkan kendali play, pause, dan volume. Beberapa source dapat disediakan sebagai format alternatif.

3. HTML5 Video

Video dengan kontrol

Autoplay, muted, dan loop

4. Video dengan JavaScript DOM

Method play() dan pause() serta property width digunakan untuk mengendalikan video.



5. YouTube dengan iframe

Video YouTube dapat disematkan menggunakan ID video pada URL embed. Contoh berikut menunjukkan iframe biasa, loop, dan kontrol yang disembunyikan.

Parameter: autoplay=1 untuk mulai otomatis, loop=1 dengan playlist untuk mengulang, dan controls=0 untuk menyembunyikan kontrol.

6. Geolocation API

Geolocation meminta izin pengguna untuk membaca koordinat lokasi. Data yang ditampilkan meliputi latitude, longitude, dan accuracy.

7. Drag and Drop API

Seret elemen di bawah dari satu kotak ke kotak lainnya. Event dragstart, dragover, dan drop digunakan dalam contoh ini.

MODUL 3 - HTML dan Bootstrap

1. Penerapan Grid Bootstrap

Bootstrap membagi halaman menjadi 12 grid. Baris berada di dalam container, sedangkan kolom menggunakan kelas col-sm-6. Pada layar kecil, kedua kolom akan tersusun vertikal.

Tampilan 1

Kolom ini menempati 6 dari 12 grid. Kelas col-sm-6 berlaku mulai dari ukuran layar tablet dan lebih besar.

Tampilan 2

Setiap baris harus berjumlah 12 grid, misalnya 6 + 6, 4 + 8, atau 4 + 4 + 4.

2. Form Registrasi Bootstrap

Form menggunakan form-group untuk setiap input dan form-control untuk elemen input serta select.
