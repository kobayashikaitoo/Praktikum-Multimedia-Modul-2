2. HTML5 Audio

Elemen <audio> memutar suara tanpa plug-in. Atribut controls menampilkan tombol play, pause dan volume. Elemen <source> menyediakan beberapa alternatif file; browser memakai format pertama yang dikenalinya. Teks di antara tag hanya tampil bila browser tidak mendukung elemen audio.

3. HTML5 Video

Elemen <video> menyematkan video di halaman web. Atribut width dan height sebaiknya selalu diisi agar halaman tidak berkedip saat video dimuat.

Video dengan autoplay + muted + loop

Atribut autoplay membuat video langsung berjalan. Browser modern memblokir autoplay yang bersuara, sehingga perlu ditambah atribut muted.

4. Video dikendalikan JavaScript (DOM Method & Property)

HTML5 menyediakan method dan property DOM untuk elemen video, sehingga video dapat dimainkan, dijeda, dan diubah ukurannya lewat JavaScript.



5. Video YouTube dengan <iframe>

Cara termudah memutar video di halaman web adalah menumpang pada YouTube, sehingga tidak perlu mengonversi video ke berbagai format. Gunakan id video pada atribut src dari elemen <iframe>. Tag <object> dan <embed> sudah deprecated sejak Januari 2015.

b. Loop (parameter playlist & loop=1)

c. Tanpa kontrol pemutar (controls=0)

Catatan parameter: autoplay=1 (langsung main), loop=1 (berulang, harus disertai playlist=id), controls=0 (kontrol disembunyikan). Nilai 0 adalah default untuk autoplay dan loop, sedangkan nilai 1 adalah default untuk controls.

6. HTML Geolocation API

Geolocation API digunakan untuk mengambil posisi geografis pengguna. Karena menyangkut privasi, posisi hanya dapat diambil setelah pengguna memberi izin. Method getCurrentPosition() mengembalikan objek koordinat.

Klik tombol untuk menampilkan koordinat anda.

7. HTML Drag and Drop API

Sebuah elemen dapat diseret bila atribut draggable="true" diberikan. Event ondragstart menentukan data yang diseret melalui dataTransfer.setData(), ondragover menentukan tempat data boleh dijatuhkan (harus memanggil preventDefault()), dan ondrop mengeksekusi penjatuhan dengan dataTransfer.getData() lalu appendChild().
